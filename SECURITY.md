# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately through
[GitHub Security Advisories](https://github.com/polarbearsrock/yoked-surface-codes/security/advisories/new)
or email [s2chitni@uw.edu](mailto:s2chitni@uw.edu). Include the affected file or
command, the impact you observed, and a minimal reproduction when possible.

The maintainers will acknowledge the report, investigate it, and coordinate a
fix or disclosure as appropriate. This research repository does not currently
publish a fixed support window or service-level response time.

## Scope

Security reports should concern the checked-in code and command-line tools.
Scientific-result questions, ordinary defects, and feature requests can use the
repository's public issue tracker.
